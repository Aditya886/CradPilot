SCREEN-BY-SCREEN UI & FEATURES BREAKDOWN
================================================================================

--------------------------------------------------------------------------------
1. Splash Screen
   File: `src/screens/auth/Splash.tsx`
--------------------------------------------------------------------------------
- Purpose: Application launch gate and session validator.
- UI Layout:
  * Fullscreen gradient background matching theme colors.
  * Centered CredPilot animated logo and brand typography.
- UI Features & Actions:
  * Automatically reads local AsyncStorage token and session data.
  * Connects to SQLite database without blocking UI.
  * Auto-navigates to BottomTab if logged in, or Onboarding / Login if new.

--------------------------------------------------------------------------------
2. Onboarding Walkthrough
   File: `src/screens/auth/Slider.tsx`
--------------------------------------------------------------------------------
- Purpose: Introduces the app's three primary value pillars to new users.
- UI Layout:
  * Horizontal swipeable carousel with 3 custom visual slides:
    - Slide 1: Debts & Social Lending Ledger.
    - Slide 2: EMI & Formal Loan Schedule Tracking.
    - Slide 3: Tuition Classes, Attendance & Fees.
  * Dot progress indicators at the bottom.
  * 'Skip' button in top-right corner.
  * 'Get Started' prominent button on the final slide.
- UI Features & Actions:
  * Swiping between slides updates page dots.
  * 'Skip' or 'Get Started' navigates directly to Signup screen.

--------------------------------------------------------------------------------
3. Login Screen
   File: `src/screens/auth/Login.tsx`
--------------------------------------------------------------------------------
- Purpose: Authentication entry point for returning users.
- UI Layout:
  * Header with welcome message and app tagline.
  * Email input box with format validation indicator.
  * Password input box with interactive eye icon to toggle visibility.
  * 'Forgot Password?' right-aligned text button.
  * Primary gradient 'Sign In' button.
  * Footer: 'Don't have an account? Sign Up' hyperlink.
- UI Features & Actions:
  * Validates email format and non-empty password before dispatching request.
  * Calls login API and shows non-blocking custom toasts on error/success.
  * Persists JWT token and switches user database upon successful login.

--------------------------------------------------------------------------------
4. Sign Up Screen
   File: `src/screens/auth/Signup.tsx`
--------------------------------------------------------------------------------
- Purpose: Two-stage account creation with App Purpose profiling and email OTP.
- UI Layout:
  * Stage 1 (User Information & Purpose Selection):
    - Full Name input field.
    - Email address input field.
    - Password & Confirm Password input fields with match verification.
    - App Purpose Selector: 3 large interactive cards (Local, Finance, Tuition)
      with descriptive icons and subtexts explaining the use case.
    - 'Continue' action button.
  * Stage 2 (6-Digit Email Verification Modal):
    - Instruction text showing the destination email address.
    - 6 individual OTP input boxes with auto-focus and clipboard paste support.
    - 45-second animated countdown timer.
    - 'Resend Code' button (enabled when timer reaches zero).
    - 'Verify & Create Account' primary button.
- UI Features & Actions:
  * Dispatches OTP to email via API; prevents duplicate signups.
  * Completes registration upon OTP verification, provisions local database,
    and navigates straight into the active app workspace.

--------------------------------------------------------------------------------
5. Forgot Password Screen
   File: `src/screens/auth/ForgotPassword.tsx`
--------------------------------------------------------------------------------
- Purpose: 3-step credential recovery pipeline.
- UI Layout:
  * Step 1: Email entry screen + 'Send Reset Code' button.
  * Step 2: 6-digit OTP verification card with countdown timer + 'Verify OTP'.
  * Step 3: New password and confirm password inputs + 'Update Password' button.
- UI Features & Actions:
  * Validates email existence with backend.
  * Enforces password security requirements.
  * Updates credentials in backend and local SQLite, returning user to Login.

--------------------------------------------------------------------------------
6. Bottom Navigation Shell & Dynamic '+' Menu
   File: `src/navigation/BottomTab.tsx`
--------------------------------------------------------------------------------
- Purpose: Core navigation bar present across all main screens.
- UI Layout:
  * 4 Tab Icons: Home, Main Section (Debts / Finance / Tuition), Insights, More.
  * Elevated Center '+' Plus Button:
    - Glowing theme circular button placed above the navigation line.
- UI Features & Actions:
  * Tapping '+' opens a customized Bottom Action Sheet tailored to active mode:
    - If Local: [Add Debt Person], [Record Debt Txn], [Create Plan/Trip], [Add Goal]
    - If Finance: [Add Loan/EMI], [Record Loan Payment], [Add Goal]
    - If Tuition: [Enroll Student], [Create Batch], [Mark Attendance], [Record Fee]

--------------------------------------------------------------------------------
7. Home Screen
   File: `src/screens/main/bottomTabs/Home.tsx`
--------------------------------------------------------------------------------
- Purpose: The main dashboard dynamically styled by user mode.
- UI Layout & Features by Mode:
  * A. Local Mode:
    - Header: User greeting, profile avatar, active mode badge, notification bell.
    - Debts Quick Card: Total to receive (green) vs Total to pay (red).
    - Plans & Trips Card: Active trips carousel with budget progress bars.
    - Savings & Goals Widget: Total saved vs total target with circular progress meter.
    - Recent Activity List: Latest 5 incoming/outgoing transactions.
  * B. Finance Mode:
    - Total Wealth & Cash Flow Card: Inflows, Outflows, Net monthly savings.
    - Next Upcoming EMI Banner: Lender name, amount due, countdown in days.
    - Active Loans Overview: Total active debts and combined monthly EMI burden.
    - Recent Payments List: Last 5 loan installments recorded.
  * C. Tuition Mode:
    - Tuition Metric Tiles: Monthly fee collections, Total pending fees.
    - Enrolled Students Card: Active student count with attendance quick link.
    - Immediate Fee Dues Carousel: Cards showing urgent overdue fees.
    - Quick Action Buttons: Direct access to Students, Batches, Attendance, Fees.

--------------------------------------------------------------------------------
8. Debts & Credit Ledger Screen
   File: `src/screens/main/bottomTabs/Debts.tsx`
--------------------------------------------------------------------------------
- Purpose: Personal lending and borrowing tracker (Digital Khata).
- UI Layout:
  * Top Summary Banner: You Will Get (green) | You Will Pay (red) | Net Balance.
  * View Toggle Pills: 'People' (by contact) vs 'Activity' (chronological transactions).
  * Search Bar: Instant contact search by name or telephone number.
  * Sort Filter: Sort alphabetically, by highest amount, or by recent transaction.
  * Contact Cards List:
    - Contact avatar initial, full name, phone number, last activity date.
    - Net balance tag: 'You will get ₹X' (green) or 'You will pay ₹X' (red) or 'Settled'.
  * Header Right Actions: CSV Export/Import button, Quick Add Person button.
- UI Features:
  * Tapping a contact opens DebtPersonDetails.
  * Real-time sync with both backend API and SQLite local storage.

--------------------------------------------------------------------------------
9. Debt Person Details Screen
   File: `src/screens/main/subScreens/DebtPersonDetails.tsx`
--------------------------------------------------------------------------------
- Purpose: In-depth statement and transaction manager for a single contact.
- UI Layout:
  * Profile Header Card: Contact name, phone, net balance amount and status.
  * WhatsApp Reminder Button: One-tap button that generates and sends a pre-formatted
    WhatsApp reminder message with amount due and payment instructions.
  * Full Transaction Ledger:
    - Date, transaction type badge (Incoming/Outgoing), amount, notes.
  * Bottom Action Bar:
    - 'You Gave' (Red button — logs cash lent).
    - 'You Got' (Green button — logs cash received).
    - 'Settle Balance' (Clears balance to zero with one tap).
  * Header Export Action: Generates exportable CSV/PDF contact statement.

12. Trip Details & Settlement Screen
    File: `src/screens/main/subScreens/TripDetails.tsx`
--------------------------------------------------------------------------------
- Purpose: Group expense breakdown, itemized spend log, and who-owes-whom matrix.
- UI Layout:
  * Header Card: Trip name, total budget, burn rate meter.
  * Participants Carousel: Horizontal list of members showing individual spend totals.
  * Smart Settlement Matrix: Auto-calculates who owes whom to settle balances with minimum transactions.
  * Expense History List: Date, item title, amount, payer badge.

16. EMI & Loans List Screen
    File: `src/screens/main/subScreens/emiLoans/EmiLoansScreen.tsx`
--------------------------------------------------------------------------------
- Purpose: Master list and liability tracker for formal loans.
- UI Layout:
  * Total Debt Liability Banner: Combined principal outstanding, total monthly EMI obligation.
  * Category Filters: 'All Loans', 'Personal', 'Home', 'Vehicle', 'Education'.
  * Loan Cards:
    - Bank/Lender Name and Loan Type tag.

--------------------------------------------------------------------------------
17. EMI Loan Detail Screen
    File: `src/screens/main/subScreens/emiLoans/EmiLoanDetailScreen.tsx`
--------------------------------------------------------------------------------
- Purpose: Loan repayment lifecycle, amortization schedule, and payment actions.
- UI Layout:
  * Account Header: Lender, account reference number, active status tag.
  * Principal vs Interest Split Cards: Total principal repaid vs interest paid to date.
  * Amortization Schedule Table: Complete month-by-month repayment breakdown.
  * Action Buttons Row:
    - 'Mark EMI Paid': Logs installment, automatically splits principal/interest, updates balance.
    - 'Undo Last EMI': Reverts erroneous payment entry.
    - 'Foreclose Loan': Calculates remaining settlement and closes loan permanently.
    - 'Delete Loan': Deletes loan record from the system.
